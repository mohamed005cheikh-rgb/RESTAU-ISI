# ISI Restaurant · Smart Ordering System

A modern, interactive web-based ordering system designed for **ISI Restaurant**.  
Built with a focus on speed, visual appeal, and seamless WhatsApp integration.

**100% Client-Side.** No backend, no databases. Just a pure front-end experience for fast food ordering.

---

### ✨ Why this system?
- Eliminate the need for paper menus or complicated POS systems.
- Provide a smooth, visual, and responsive experience for customers on both mobile and desktop.
- Directly integrate with WhatsApp for instant order processing.

---

### 🔧 Key Features
- **📋 Smart Menu Sections:** Breakfast, Lunch, Dinner, Desserts, Snacks, and Healthy Drinks.
- **🎨 Neon Visual Identity:** Unique glowing brand identity with rotating emojis for a vibrant feel.
- **📱 Fully Responsive:** Optimized for mobile phones and tablets (touch-friendly).
- **🛒 Interactive Order Cart:** Dynamic selection, removal, and live cart updates.
- **💬 WhatsApp Integration:** One-click "Send Order" button generates a pre-filled WhatsApp message for the restaurant owner.
- **🌙 Dark/Light Video Background:** Static video background with a cinematic overlay for an immersive atmosphere.
- **🖥️ PWA Ready:** Includes a `manifest.json` for potential installability.

---

### 🚀 Quick Start (For the Customer)
1. Browse the menu cards (Breakfast, Lunch, etc.).
2. Select a meal from the dropdown menu.
3. Your selection appears in the **"Order Summary"** cart.
4. Click **"Send Order via WhatsApp"**.
5. Your order message opens in WhatsApp automatically.
